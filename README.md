# What is combava ?

Combava is an opinionated markdown to PDF Generator. It's a personal project that i'm going to use for school. I was tired of constantly copying and pasting my report templates over and over, so I made this tool. I'm studying CS engineering, and since markdown is propably the most "gitable" text format, I chose it.
