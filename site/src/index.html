Du markdown au PDF,
sans réglage.

Combava est un générateur de rapports PDF opinioné. On écrit du markdown avec un petit en-tête TOML, combava rend un rapport fini. Pas de style à régler, pas de template à installer.

« Avec un peu de combava, ça passe mieux ! »

Lire le guide Voir sur GitHub 
git clone https://github.com/bobbysenior/combava
cd combava && make install
combava init rapport.md && combava build rapport.md

En développement actif : pas encore de première version publiée.

Pourquoi combava

Le contenu d'abord

À chaque rapport, on recopiait le même template LaTeX ou Word pour le retoucher à la main. Ici, on n'écrit que le texte.

Un format « gitable »

Le markdown est le format texte qui se versionne le mieux : un diff de rapport se lit, une fusion fait rarement mal.

Un seul binaire

Typst est intégré. Pas de LaTeX, pas de Pandoc, pas de CLI Typst à installer : make install suffit.

À quoi ressemble un document

Un en-tête TOML pour la couverture, puis du markdown. Les callouts, les formules, les légendes de code, les citations et la table des matières sont pris en charge.

Le chemin est court et lisible : le markdown est transpilé en Typst, puis compilé en PDF. Une erreur renvoie à la ligne et à la colonne de votre markdown.

rapport.md→ Typst→ rapport.pdf 

+++
title = "Sécurité des réseaux"
subtitle = "Compte rendu de TP 3"
authors = ["Ada Lovelace", "Alan Turing"]
date = "10 octobre 2026"
toc = true
bibliography = "references.bib"
+++

# Introduction

Combava transforme le markdown en PDF
grâce à Typst [@typst2023].

> [!WARNING]
> Les callouts suivent la syntaxe GitHub.

Les maths s'écrivent en LaTeX : $E = mc^2$.

Des choix assumés

Combava décide à votre place. Ce ne sont pas des manques, et ils ne sont pas dans la feuille de route.

  • Un template, un style. Aucune option de mise en forme. Pour changer d'apparence, on remplace le template.
  • Le français. Guillemets et typographie suivent les règles françaises, sans réglage de langue.
  • Un en-tête fermé. Une clé inconnue est une erreur : autors = […] arrête la compilation au lieu de produire un PDF sans auteur.
  • Les erreurs bloquent. Image distante, lien interne cassé, citation sans bibliographie : pas de PDF.
  • Un échec ne détruit rien. Le dernier bon PDF reste en place jusqu'à ce que le nouveau soit prêt.
  • Même entrée, même sortie. Le transpileur est une fonction pure, donc testable et fiable.
